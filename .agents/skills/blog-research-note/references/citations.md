# 인용 검토

- 본문에서 사용하는 논문·모델·데이터셋·benchmark·코드를 원출처로 확인한다. 논문 페이지, DOI, arXiv, 공식 모델·데이터셋 페이지, 저장소와 release를 우선한다. 검색 결과 요약만으로 검증했다고 보고하지 않는다.
- 논문의 제목·저자/기관·연도·venue/preprint·DOI/arXiv, 모델과 데이터셋의 공개 이름·provider·해당 version, 코드의 project·owner·공식 링크를 가능한 범위에서 대조한다.
- 본문과 caption의 출처 이름, 인용 번호, reference entry를 일치시키고 중복만 정리한다. 근거 없는 유명 논문을 추가해 주장을 보강하지 않는다.
- 구체적인 reference / text citation / BibTeX 형태는 템플릿의 `Reference List`와 `Citation` 예시를 따른다. 글 자체의 저자·제목·연도·canonical URL과 일치시키고 key는 안정적이고 중복 없이 유지한다. 필수 공개 구조는 스킬 진입점에서 관리한다.
- 본문에서 널리 사용하는 출처가 빠졌는지, 추가 entry가 실제 관련 있는지 확인한다. DOI나 landing page의 정상 redirect를 오류로 취급하지 말고 최종 도착한 출처의 정체성을 확인한다.
- 확인할 수 없는 메타데이터는 추정하지 않는다. 편집 중에는 구체적 TODO 또는 검토 메모를 남기고, 검토 전용이면 위치와 미확인 항목을 보고한다. 비공개 notebook·run 경로를 공개 참고문헌으로 연결하지 않는다.

확인한 링크와 메타데이터, 미확인 근거를 보고한다. 인용 작업을 이유로 실험 해석·수치·결론을 바꾸지 않는다.
