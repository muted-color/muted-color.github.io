# Codex instruction and workflow audit

검토일: 2026-09-06. 대상: 이 저장소의 `AGENTS.md`, `.codex/config.toml`, 역할 5개, 글 템플릿, README/SEO, 개발·검증 workflow. 기존 저장소에는 `skill.md` / `SKILL.md`와 `.github/workflows`가 없었다. 새 저장소 스킬은 `.agents/skills/blog-research-note/SKILL.md`에 둔다. 전역 설치 스킬과 사용자 설정은 수정하지 않았다.

## 설정과 검증

- 검증한 CLI는 `0.153.4`. 감사 당시 사용자 설정의 모델은 `gpt-6-astra`, 부모 effort는 `xhigh`였다. 감사 중 추가했던 프로젝트 모델 고정은 후속 사용자 요청으로 제거했다. 부모 effort와 좁은 전문 역할 5개의 기존 `medium`은 유지했다.
- 동시 자식 수 6과 기존 `max_depth = 1`은 유지했다. depth 키는 설치된 CLI의 strict config에서 수용되며, 커스텀 역할의 재위임 금지도 명시했다.
- TOML 6개 파싱, skill-creator `quick_validate.py`, 로컬 문서 링크와 diff 확인을 수행했다. `codex debug prompt-input`에서 새 루트 지침과 repo skill discovery를 확인했다. 이 명령은 모델의 실제 작업 성능 평가가 아니다.
- `codex --strict-config doctor --summary`의 설정 검사가 통과했다. 초기 비대화형 셸의 `TERM=dumb` 진단은 임시 `TERM=xterm-256color`로 재확인했으며 사용자 환경 설정은 바꾸지 않았다. `--strict-config`는 debug 하위 명령에는 지원되지 않아 doctor로 검사했다.
- `bash scripts/jekyll.sh check`, bundled Ruby, shell syntax, 잘못된 CLI 인자 처리와 격리 Jekyll 빌드가 통과했다. 설치가 필요하지 않아 `setup`의 네트워크 설치 경로는 실행하지 않았다.
- build warning인 선택적 `faraday-retry` 부재는 빌드를 실패시키지 않았다. 해당 gem이나 잠금 파일은 변경하지 않았다.
- 실행 중 서비스의 `_site`, lockfile, Bundler config와 Jekyll metadata를 검증 빌드가 변경하지 않았음을 확인했다. 서비스는 재시작 없이 active이고 localhost HTTP 응답을 확인했다.
- 기존 사용자 변경·미추적 파일 14개를 작업 시작 시 SHA-256과 대조해 보존했다. 실제 게시물 수치·본문·시각 자산은 이번 감사의 수정 대상이 아니다.
- 독립 검토는 영문 오탈자, 근거가 일부 빠진 새 글, 이미 QA를 마친 Figure의 최종 검토, 글과 무관한 스크립트 수정 시나리오를 다뤘다. 새 글/최종 검토 경로에서 Citation 필수 구조가 빠질 수 있는 문제를 발견해 스킬 진입점으로 통합했다. 미완성 신규 글의 draft 상태도 명시했다.

## 효과와 한계

루트 AGENTS는 11,802 → 4,339 bytes, 루트와 5개 역할 합계는 54,368 → 12,547 bytes로 줄었다(76.9%). 새 스킬과 참조 13,194 bytes까지 합치면 25,741 bytes로 기존 대비 52.7% 감소했다. 상세 규칙 일부를 선택적으로 읽는 스킬로 이동한 결과이며, 모든 문맥이나 실제 토큰 사용량이 이 비율로 감소한다는 뜻은 아니다.

검증된 개선은 중복 감소, 역할/규칙 충돌 해소와 실제 로딩·빌드 동작이다. Astra의 정확도·처리시간·토큰 비용 개선은 전후 모델 실행 비교를 하지 않았으므로 수치로 주장하지 않는다. 이후 같은 입력의 글 수정·신규 초안·Figure·인용 작업에서 정확성, 불필요한 질문/위임/반복 검사, 시간과 토큰을 비교해 조정한다.

새 지침·역할 적용은 새 Codex 세션에서 확인한다. 이 작업에서는 commit, push, 공개 배포, 전역 스킬 교체, 서비스 재시작이나 모델 API benchmark를 수행하지 않았다.
